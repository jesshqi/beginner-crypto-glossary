# beginner-crypto-glossary

Plain-English crypto definitions and a learning roadmap for beginners.
No jargon, no assumptions, no money required.

## Files

| File | What it is |
| ---- | ---------- |
| `GLOSSARY.md` | Plain-English definitions: wallet, seed phrase, gas, testnet, NFT, approval, and more. |
| `ROADMAP.md` | A step-by-step path from zero to confident, with links to hands-on tools. |

## Companion repos (hands-on tools)

| Repo | What it does |
| ---- | ------------ |
| [testnet-starter-kit](https://github.com/jesshqi/testnet-starter-kit) | Start on a testnet: get free test ETH and check your balance. |
| [free-mint-safety-checker](https://github.com/jesshqi/free-mint-safety-checker) | Check a mint contract before you mint. |
| [token-approval-checker](https://github.com/jesshqi/token-approval-checker) | See what your wallet has approved. |

| [first-nft-contract](https://github.com/jesshqi/first-nft-contract) | Your first NFT smart contract (Solidity). |
| [tzero-testnet-helper](https://github.com/jesshqi/tzero-testnet-helper) | Check Tzero testnet points, balance, and missions. |

## Safety

- This repo contains **no private keys, seed phrases, or API keys**.
- Nothing here asks for your wallet, your seed phrase, or your money.
- The single most important rule: **never share your seed phrase or
  private key with anyone.**
